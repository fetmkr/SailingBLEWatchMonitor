# Sail Analyzer

경기정 모듈이 기록한 `.HLG` 파일을 받아 타임라인으로 본다.
설계는 저장소 뿌리의 `TRANSFER.md`, 파일 규격은 `docs/spec/` 에 있다.

```
npm install
npm run tauri dev      만들면서 보기 (시험용 데이터가 저절로 열린다)
npm run tauri build    배포판
```

## 왜 Tauri 인가

윈도에서는 WebView2 가 곧 Chromium 이다. 맥만 WebKit 인데, 필요한 것이
다 있고 (`requestVideoFrameCallback` Safari 15.4+, WebCodecs 16.4+) HEVC 는
오히려 맥이 기본 지원한다. Electron 은 설치 파일이 150 MB, Tauri 는 10 MB 다.

**Rust 는 얇게 둔다.** 파일 열고 저장하고 보드에서 받아오는 것만 Rust 고,
읽고 그리는 것은 전부 TypeScript 다. 실측으로 8시간 세션(88.7 MB, IMU 288만
줄)을 **2.3초**에 읽는다. 파서를 Rust 로 옮길 이유가 아직 없다.

```

src/panes.ts      칸 나누기. 붙어 있는 칸 사이마다 나누개를 만든다
src/map.ts        항적 지도 (MapLibre + OpenStreetMap + OpenSeaMap)
src/ble.ts        보드를 블루투스로 찾고 WiFi 를 켜라고 시킨다
src/protocol.ts   UUID 등. ★ 사본이 넷이다 — PROTOCOL.md 참조
src/library.ts    보관함. 원본 파일과 코치가 적은 것을 갈라 둔다
src/video.ts      영상 시각 맞추기
src/main.ts       화면과 조작
public/sample.HLG 시험용 데이터 (tools/hlog_make_fixture.py 로 만든다)
```

## 조작 — Saleae Logic 과 같게

```
휠 / 트랙패드 위아래   커서가 놓인 시각을 붙잡고 확대·축소
트랙패드 좌우          밀기
시프트 + 휠            밀기
끌기                   그 자리에 고정 (훑기)
시간 축 끌기           밀기
두 번 누르기           그 자리로 당기기
아래 띠 클릭·끌기      그 자리로 건너뛰기
```

**단축키는 없다.** 창 전체에서 키를 받고 있어서, 보드 주소에 192.168.0.76 을
치려고 1 을 누르면 왼쪽 칸이 닫혔다. 있는 일이 전부 단추와 마우스로 된다.

**확대할 때 커서 아래 시각이 제자리에 있어야 한다.** 가운데를 기준으로
확대하면 보고 있던 곳이 화면 밖으로 달아난다.

## 왼쪽 이름 칸 — Saleae 방식

값 그림 바깥에 이름 칸을 둔다. 이름을 그림 안에 얹으면 값과 겹쳐서 둘 다
읽기 어렵다.

```
■ Speed Over Ground     6.9 kn
                        ~~~~~~
                        3.9 kn
```

**한 줄이면 된다.** 색은 이름 앞의 작은 네모가 준다. 그림의 선 색과 이어진다.

처음에 짧은 표시(`SOG`)와 이름(`Speed Over Ground`)을 나란히 뒀다가 뺐다 —
같은 말을 두 번 쓰는 셈이었다. Saleae 의 `D0` 는 하드웨어 채널 번호라 이름과
다른 것이지만 우리는 그게 아니다.

단위도 세로축 숫자에 붙인다. 이름 칸에 쓰면 줄이 늘어난다. Saleae 가
`5 V` 라고 축에 적는 것과 같다.

**경계를 끌면 칸이 넓어진다.** 이름이 길면 넘친다. 넘치는 만큼은 말줄임(…)
으로 자른다 — 그냥 넘치면 옆 칸 숫자와 겹쳐서 둘 다 못 읽는다. 70~360 픽셀
사이에서 움직이고 고른 너비는 남는다.

**이름을 누르면 고칠 수 있다.** 사람마다 다르게 부른다 — 어떤 코치는 "Trim",
어떤 코치는 "Pitch" 다. 고친 것은 남는다. `Enter` 로 넣고 `Esc` 로 물린다.

기본 이름은 영어다. 클래스도 대회도 영어로 돌아가고, 다른 분석 도구와
나란히 볼 때 말이 맞아야 한다.

```
SOG    Speed Over Ground     kn
HEEL   Heel                  deg
TRIM   Trim                  deg
YAW    Yaw Rate              deg/s
HEAVE  Vertical Accel        g
COG    Course Over Ground    deg
SAT    Satellites            count
```

## 시간 축 — Saleae 방식

축을 **위**에 둔다. 눈이 먼저 가는 자리다.

```
2:53          +43 ms        +143 ms
```

맨 왼쪽에 기준 시각을 굵게 적고, 그 뒤로는 거기서 얼마나 떨어졌는지를
**단위와 함께** 적는다. 단위가 없으면 크게 당겼을 때 `0:02` 가 2초인지
2분인지 헷갈린다. 배율에 따라 ms · 초 · 분으로 저절로 바뀐다.

## 맨 아래 스크롤 막대

파형을 다시 그리지 않는다. **손잡이 길이가 곧 배율이다** — 크게 당길수록
짧아지고 전체를 보면 꽉 찬다. 같은 속도 그림을 아래에 또 깔면 눈만 어지럽다.

막대 위에 마우스를 올리면 커서가 손바닥으로 바뀐다. 잡아서 끌 수 있다는 뜻이다.

## 그리기 — 봉우리를 잃지 않는다

8시간이면 IMU 가 288만 점이다. 그대로 그리면 못 쓴다. 화면 가로 픽셀 수만큼
구간을 나누고 **구간마다 최소·최대만** 남겨 세로줄 하나로 그린다.

평균을 쓰면 안 된다. 파도로 튄 봉우리가 사라진다. **그 봉우리가 우리가
100 Hz 로 기록한 이유다.**

**아주 당겨서 점이 성길 때는** 실제 점을 이어 긋고 동그라미를 찍는다.
픽셀마다 세로줄을 그으면 점 하나가 점 하나로만 보여서 흐름을 못 읽는다.
어디가 실제로 잰 자리인지 눈에 보여야 한다 — 사이는 그냥 이어 놓은 선일 뿐이다.

## 브라우저에서 만들 때

`npm run dev` 만 띄우고 브라우저로 `localhost:1420` 을 열면 훨씬 빠르다.
Tauri 가 없으면 이렇게 대신한다.

| | 앱 | 브라우저 |
|---|---|---|
| 보관함 목록 | `library.json` | localStorage |
| 기록 파일 | `logs/` 아래 | 램 (새로 읽으면 사라진다) |
| 보드 붙기 | Tauri http | 보통 fetch |

### 브라우저로 못 보는 것

**숨겨진 탭에서는 `requestAnimationFrame` 이 아예 안 돈다.** 자동화로
시험할 때 이것 때문에 세 가지가 안 된다.

- 영상이 안 읽힌다 (`readyState` 가 0 에서 안 올라간다)
- 지도가 안 그려진다 (타일을 요청조차 안 한다)
- 미뤄 둔 다시 그리기가 영영 안 일어난다

그래서 **미루지 말고 바로 그린다.** `applyTheme` 이 그 예다.

**칸 크기는 브라우저로 확인이 안 된다.** 같은 코드인데 앱에서만 칸 아래가
60px 빈 적이 있다. 앱이 스스로 재서 파일로 떨구게 해야 한다.

```ts
// import.meta.env.DEV 안에서만
writeTextFile("debug-size.txt", line, { baseDir: BaseDirectory.AppData })
```

읽는 곳은 `~/Library/Application Support/kr.fetm.sailanalyzer/`.
다 쓰고 나면 지운다. 앱 창의 콘솔은 터미널로 안 나온다.

### 왼쪽에는 서랍을 두지 않는다

그 자리는 타임라인의 이름 칸이 쓴다 (Speed Over Ground, Heel …).
양옆에 서랍을 두면 가운데가 양쪽에서 깎이는데, **타임라인은 높이보다
너비가 생명이다.**

예전에는 위가 여섯 줄이었다. 파일 이름·세션·NAV/IMU·IMU 종류·영상·상태.
한 번 읽고 마는 내용이 화면 높이의 15%를 계속 먹었다. 서랍과 아래 줄로
옮기고 한 줄로 줄였다.

## 칸 크기 — 붙어 있는 칸 사이마다 나누개

```
잡아 끌기      크기 조절
두 번 누르기    두 칸을 반반으로
⇅ 위아래       가운데를 위아래로 놓을지 좌우로 놓을지
넓게           서랍을 통째로 접는다
```

칸을 접거나 펴면 나누개도 따라서 다시 놓인다. 어긋날 자리가 없다.

### 접은 칸은 사라지지 않는다

28픽셀짜리 얇은 띠로 남는다. **누르면 다시 펼쳐진다.**

```
▸ 영상          ▸ 지도
──────────────────────────────
       데이터 (다 씀)
```

아주 없애 버리면 어디로 갔는지, 어떻게 되돌리는지 알 수가 없다.
마지막 한 칸까지 접는 것은 막는다.

**빠져나올 길**: 설정 서랍의 "처음 배치로 되돌리기". 색과 보관함은 그대로
두고 배치만 되돌린다.

## 센서 줄 접기

일곱 줄을 다 펴 두면 하나하나가 납작하다. 이름 앞의 ▾ 를 누르면 그 줄이
접히고, 남는 자리는 펼친 줄들이 나눠 갖는다. **하나만 펴 두면 그 하나가
화면을 다 쓴다.**

```
하나 접으면   접힌 줄 23,  나머지 108 씩
다 펴면       96 씩
```

접은 줄은 이름만 남는다. 마지막 한 줄까지 접는 것은 막는다.

## 커서 — 훑기와 고정

```
마우스를 옮기면    옅은 선이 따라온다. 영상도 같이 훑어진다
그림 위를 끌면     고정 자리가 따라오고 영상이 계속 훑어진다
떼면              그 자리에 박힌다 (파란 선 + 위쪽 삼각형)
Esc               고정을 푼다
```

**그림 위를 끄는 것은 훑기다. 화면 밀기가 아니다.** 영상 편집기에서 재생
머리를 끄는 것과 같다. 밀기는 이미 길이 넷이나 있다.

```
시프트 + 휠        밀기
트랙패드 좌우      밀기
아래 스크롤 막대   잡아서 밀기
위 시간 축 끌기    잡아서 밀기
```

그림 위까지 밀기로 쓰면 정작 훑을 데가 없어진다.

**박아 두지 않으면 화면을 볼 수가 없다.** 마우스를 뗄 때마다 풀리면 영상을
보려고 눈을 옮기는 순간 자리를 잃는다. 그래서 떼면 그 자리에 남는다.

## 싱크 — 단추 하나

```
싱크      누르면 지금 영상 화면과 파란 선 자리를 맞추고 물린다
싱크 ●    다시 누르면 푼다
```

**파란 선은 파일을 열면 바로 생긴다.** 데이터 창을 눌러야 생기게 뒀더니,
영상만 만지던 사람은 선을 본 적이 없어서 싱크가 "맞출 자리가 없다" 고
거절했다. 거절당했으니 안 물리고, 안 물렸으니 영상이 돌아도 데이터가 안
움직였다. 늘 어딘가는 가리키고 있어야 한다.

**누르기 전에는 영상과 데이터가 따로 움직인다.** 그래야 맞출 수 있다.

맞추는 방법이 이렇기 때문이다. 영상을 태킹하는 장면에 두고, 타임라인에서
힐이 넘어가는 자리를 누르고, 그때 `싱크` 를 누른다. 그런데 둘이 붙어 다니면
하나를 옮길 때 다른 하나도 따라가서 **애초에 맞출 수가 없다.**

파일이 적어 둔 시각으로 짐작은 해 두지만 그건 짐작일 뿐이다. 카메라 시계가
틀린 경우가 잦아서 사람이 눌러 확인해야 한다.

영상 칸 아래에 지금 어느 쪽인지 나온다.

```
따로 움직임 — 같은 순간에 두고 [싱크]   (짐작 +21.0초)
같이 움직임 · 영상 0초 = +2분 53.3초
```

싱크가 걸리면 타임라인 숫자가 영상 재생 시간과 같아진다. 영상이 1:23 일 때
타임라인도 1:23 이다. 서로 다른 숫자를 보면서 맞추려면 머릿속으로 계속 빼야
한다.

### 수동으로 밀기

`−10초` `−1초` `+1초` `+10초` 로 어긋난 만큼 민다. 누른 부호대로 아래 숫자가
움직인다.

## 영상 슬라이더

영상 칸 아래에 있다. 타임라인 없이 영상만 훑을 때 쓴다.

**싱크가 걸려 있을 때만 타임라인이 따라온다.** 안 걸렸으면 영상만 움직인다 —
그래야 맞출 자리를 잡을 수 있다.

재생 중에는 고정 자리가 영상을 따라간다. 지금 보는 프레임이 타임라인 어디인지
보여야 한다.

## 주황 점선 = 마킹

선수가 배에서 **버튼을 눌러 "이 순간" 이라고 찍어 둔 자리**다. 깃발과 번호가
붙는다. 커서를 가까이 대면 아래 읽기값에 `⚑ 마킹 3` 이라고 나온다.

시험용 데이터에는 3분마다 하나씩 일부러 넣어 뒀다 — 그리기가 되는지 보려는
것이다. 진짜 기록에는 버튼을 누른 자리에만 있다.

## 고정 선

```
점선 (옅음)    마우스를 따라다니는 커서
굵은 파란 선   눌러서 고정한 자리. 시간 축에 시각 알약, 아래에 삼각 손잡이
```

어두운 바탕에 얇은 선 하나는 눈에 안 들어온다. 굵게 긋고 알약을 붙였다.
