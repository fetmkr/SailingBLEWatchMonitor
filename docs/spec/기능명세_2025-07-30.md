## 경기정용 센서 모듈

**데이터 저장**

- 저장 버튼을 눌러 기록 시작/종료 — 선수가 명확히 통제
- 32GB microSD, 초당 10회(10Hz) 기록, 수천 시간 저장 — 용량 걱정 없음
- GPS UTC 시각 기준으로 기록 → 다른 배·영상과 자동 정렬
- 코치보트 없어도 단독 기록
- **저장 항목**
    - UTC 시각 + 밀리초
    - GPS: 위도, 경도, 속도(SOG), 방향(COG), 위성수, 측위정확도, fix 상태
    - 자세: 힐각(roll), 트림(pitch), 헤딩(yaw)
    - 가속도 3축, 자이로 3축, 지자기 3축
    - 시스템: 배터리, 세션ID, 이벤트 플래그(마킹), CRC

**실시간 통신**

- 코치보트로 LoRa 최대 5km 직접 전송 — 중계 장비 불필요
- 코치가 여러 선수를 태블릿에서 동시 모니터
- 통신 끊겨도 SD 기록은 계속 → 데이터 손실 없음
- **전송 항목 (0.5~10Hz 거리에 따리 가변)**
    - 모듈 ID
    - UTC 시각
    - 위도, 경도
    - 속도(SOG), 방향(COG)
    - 힐각
    - 배터리·상태, CRC
- 선수 폰·워치로 BLE로 데이터 실시간 표시

**조작**

- 전원 On/Off 버튼
- 데이터 저장 시작/종료 버튼
- LED 상태 표시: 준비 중(주황 깜박) / 기록 중(녹색 깜박) / 배터리 부족(빨강) / 오류(빨강 빠름)

**초기 설정·캘리브레이션**

- 장착 후 배가 수평일 때 **힐각 영점 조정** (앱 또는 버튼) — 배마다 장착 각도가 달라 필수
- 지자기 캘리브레이션
- 선수 배정, 통신 채널 설정 (한 번 하면 유지)

**전원·관리**

- 18650 배터리 교체형 — 수명 후 배터리만 교체
- 하루 훈련 충분, USB-C 범용 충전
- 배터리 잔량 LED 알림

**내구성**

- IP68 완전 방수 (에폭시 포팅) — 전복·물벼락 견딤
- 바닷물 부식 대응 (알루미늄 아노다이징 구조)
- 클래스별 전용 브래킷: ILCA, 470, 49er, iQFoil
- 화면이 없어 대회 중에도 장착 출전 가능

**펌웨어 업데이트**

- BLE 무선 업데이트(OTA) — 폰 앱으로 간단히
- USB-C 유선 업데이트 지원 (복구용)
- 기능이 계속 추가·개선됨 (구매 후에도 진화)

**폰·워치 앱**

- 모듈 설정 (선수 배정, 통신 채널, 힐각 영점)
- 실시간 데이터 확인
- 데이터 회수·클라우드 업로드
- 리그 튜닝 기록 입력
- 워치 손목 표시

**유지보수**

- 국내 즉시 A/S
- 커스텀 기능 요청 대응

**2년차 확장**

- 레이스 매니지 먼트: OCS(스타트 라인 침범) 자동 체크
- VMG·폴라차트 연동
- 러더 센서 등 추가 센서 BLE 연결

## 코치보트 데이터 모니터링 시스템

**환경 데이터 측정**

- 풍향·풍속 실시간 측정 (마스트 상단 센서)
- 선속계로 대수속도(STW) 측정 → GPS 대지속도와 비교해 **조류 자동 산출**
- GPS 위치·속도·방향
- 파도 상태 (상하 가속도 기반)
- 진풍(TWA/TWS) 계산 → 선수별 VMG 산출 기반
- **측정 항목**: 풍향(AWA/TWD), 풍속(AWS/TWS), 조류 방향·속도, 자기 위치·속도·헤딩, UTC 시각

**함대 실시간 수신**

- 여러 경기정의 LoRa 텔레메트리 동시 수신 (최대 5km)
- 각 선수의 위치·속도·방향·힐각 실시간 취합
- 수신 데이터 + 자기 환경 데이터를 UTC로 정렬해 저장
- 통신 품질(RSSI) 모니터링 — 어느 선수가 범위 밖인지 확인

**코치 태블릿 앱**

- 지도 위에 전 선수 위치 실시간 표시
- 선수별 속도·힐각·방향 동시 확인
- 풍향·조류 오버레이 — 왜 그 코스가 유리한지 시각적으로 확인
- **선수별 VMG 계산·표시** (코치보트 풍향 데이터 기반)
- 선수 간 비교 (같은 시각 나란히)
- 세션 관리: 참가 선수 확인, 모듈↔선수 매핑
- 리그 튜닝 확인·대리 입력
- 오프라인 동작 — 인터넷, 클라우드 연결 없어도 태블릿에서 모니터링

**클라우드 연동**

- LTE로 클라우드 실시간 업로드
- 인터넷 끊기면 로컬 버퍼링 후 자동 재전송
- 육상 복귀 시 일괄 동기화

**전원·안정성**

- 독립 배터리 + 전원 안정화 (엔진 시동·발전 노이즈 대응)
- 전원 끊겨도 자동 재시작, 데이터 이어서 기록
- 경기정 모듈은 코치보트와 무관하게 독립 기록 (단일 실패점 없음)

**설치 구성**

- 센서 마스트 제작·설치 (풍향풍속계·GPS, 장거리 통신 모듈 거치)
- NMEA 2000 백본 설치·결선
- 보트 속도계 설치
- 제어유닛·통신 장비 설치
- 배터리·전원 배선
- 센서 캘리브레이션 (풍향계 정렬, 영점)

**2년차 확장**

- OCS(스타트 라인 침범) 자동 체크
- 자동추적 카메라 연동
- 영상 스트리밍
- GPS 정밀도 향상
    - 인터넷으로 RTCM 보정 정보 수신 (국토지리정보원 무료 서비스 또는 상용)
    - 경기정들에 보정 정보 재전송 → 서브미터급 정확도

## 데이터분석 및 시스템 운영 소프트웨어

**계정·권한**

- 등급: 관리자(협회) / 코치 / 선수
- 선수도 로그인해 자기 훈련 직접 관리
- 세션 생성자가 공개 범위 설정 (기본: 같은 세션 참가자 데이터 상호 조회)
- 관리자는 전체 조회

**세션 관리**

- 코치가 세션 생성 (날짜·장소·훈련/레이스 구분) 1 년차에는 훈련위주로
- 선수 배정, 모듈↔선수 매핑
- 여러 배 + 코치보트 데이터를 **UTC 기준 자동 그룹핑**
- 자동 판정 결과를 코치가 확인·수정

**환경 데이터**

- 코치보트 센서에서 자동 입력 (시계열)
- 혼자 훈련 시 선수가 수동 입력 (풍향·풍속·파도 간단 선택)
- 수동 오버라이드 가능, 원본 보존 + 출처 표시 (센서/사람)

**리그 튜닝 기록**

- 선수가 자기 폰·웹으로 출항 전 입력
- 클래스별 전용 항목 (ILCA/470/49er/iQFoil)
- 직전 세션 세팅 불러오기 — 조금씩만 수정
- 코치 대리 입력·수정 가능
- 조건 + 세팅 + 성능이 한 세트로 축적

**데이터 분석**

- 트랙 재생 (지도 위 항적 리플레이)
- 환경데이터 풍향 풍속 조류 그래프
- 속도·힐각·방향 그래프
- 선수 간 나란히 비교 (같은 시각, 같은 조건)
- 세션별 레포트 자동생성 (pdf)

**미디어 연동**

- GoPro·폰 영상·사진 업로드
- 촬영 시각(EXIF/GPMF) 자동 인식 → 세션 자동 매칭
- 시각 오류 수동 보정 (오프셋 입력, 싱크 포인트 지정)

**선수 개인 관리**

- 내 세션 이력, 누적 훈련 시간·거리
- 내 튜닝 노트 축적 — 개인 자산이 됨

**데이터 관리**

- CSV·GPX 등 내보내기
- 백업·보안
- 해외 원정 대응 (오프라인 후 동기화)

**2년차 확장**

- 데이터 분석: 조건별 검색: "12kt 강풍에서 어떤 세팅이 빨랐나"
- 데이터 분석: 태킹·자이빙 등 매뉴버 자동인식
- 데이터 분석: 함대 데이터 통한 조류 자동 보정
- 데이터-영상 타임라인 동시 재생 (그래프 클릭 → 영상 점프)
- VMG·폴라차트 자동 생성·축적
- 레이스 매니지 먼트: 레이스 대회 경기정 트래킹 뷰어
- 레이스 매니지 먼트: OCS 판정 결과 표시
- 레이스 매니지 먼트: 함대 통합 실시간 관제 화면
